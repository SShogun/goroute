# GoRoute Implementation Plan

> **Goal:** Build `goroute`, an ultra-lightweight, production-ready LLM gateway and multi-provider router in Go (< 15MB RAM idle) with OAuth PKCE support (Antigravity), multi-account rotation, automatic failover combos, quota tracking, and an OpenAI-compatible API.

**Architecture:** A single statically linked Go binary. Uses `net/http` and `go-chi/chi` for the HTTP proxy layer, native SSE streaming with `http.Flusher`, in-memory sliding window rate-limiting with encrypted SQLite token storage, and embedded static dashboard via `embed.FS`.

**Tech Stack:** Go 1.27+, `github.com/go-chi/chi/v5`, `gopkg.in/yaml.v3`, `github.com/spf13/cobra`, standard Go crypto (AES-GCM).

## Global Constraints
- Target RAM: < 15MB at idle.
- Zero external runtime dependencies (no Node, no Python, no esbuild).
- OpenAI-compatible `/v1/chat/completions` and `/v1/models` API with full SSE streaming.
- Native OAuth PKCE flow with local callback server for Antigravity accounts.
- Automatic retry/fallback cascade on 429/5xx status codes.
