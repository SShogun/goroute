# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

GoRoute handles sensitive OAuth tokens and API keys. We take security very seriously.
If you discover a security vulnerability or potential token leakage:

1. **Do NOT open a public GitHub issue.**
2. Please privately email the maintainer or submit a Private Vulnerability Advisory via GitHub.
3. You will receive an acknowledgment within 48 hours with a remediation timeline.
